# Customer guide

1. Open the payment page from the print shop.
2. Check that the displayed payee name and UPI ID match the shop.
3. Tap **Pay via UPI**. If the phone has a compatible UPI app installed, it opens with the payee prefilled.
4. Enter or review the payment amount in the UPI app. Verify the payee before confirming.
5. Return to the shop and show the completed payment in the UPI app if requested.

The website only hands the payment request to the UPI app. It cannot see or verify the result of the transfer.
